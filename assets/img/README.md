# Hero-изображения ЭЛЕМЕНТ

Сайт уже подключён к двум hero-визуалам. Положите сюда два файла — и реальные
рендеры автоматически заменят векторные плейсхолдеры (если файлов нет, вёрстка
не ломается: показывается `genset.svg` / градиент).

| Файл | Что это | Где используется |
|------|---------|------------------|
| `hero-dark.png`  | Тёмный hero: фотореалистичный двигатель с пламенем на чёрном, бренд «ЭЛЕМЕНТ» | превью карточки 2 на главной, OG-изображение (главная, вариант 2) |
| `hero-light.png` | Светлый hero: двигатель с медными трубами на белом, «Энергия для развития бизнеса» | превью карточки 1 на главной, фоллбэк двигателя в `variant-1.html`, OG-изображение (вариант 1) |

## Как добавить

1. Скачайте оба PNG по ссылкам из чата (экспорт Canva, Pro-качество).
2. Сохраните их в эту папку строго под именами `hero-dark.png` и `hero-light.png`.
3. Закоммитьте и запушьте — всё подхватится автоматически, правок в коде не нужно.
