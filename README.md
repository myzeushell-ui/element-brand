# ЭЛЕМЕНТ — брендбук

Фирменный стиль вычислительной техники **ЭЛЕМЕНТ**: белый корпус, медный
акцент, шестиугольная эмблема. Проект — статический сайт-презентация без
сборки, готовый к деплою на Vercel.

## Что внутри

| Файл | Назначение |
|------|------------|
| `index.html` | Светлая версия презентации брендбука |
| `dark.html`  | Тёмная версия |
| `3d.html`    | Интерактивный 3D-концепт GPU (three.js, CDN) |
| `assets/`    | Эмблема и продуктовая фотография |
| `viewer/`    | Задел под финальную 3D-модель (Hunyuan `.glb` + `viewer.html`) |
| `tools/genassets.js` | Генератор плейсхолдер-PNG (чистый Node, без зависимостей) |

В шапке `index.html` и `dark.html` — перелинковка **Светлая · Тёмная · 3D**.

### assets/

- `badge.svg` — векторная эмблема (основной знак)
- `badge.png` — растровая эмблема
- `gpu_white.png` — белый GPU, базовый
- `gpu_white_copper.png` — белый GPU с медным акцентом
- `gpu_white_badged.png` — белый GPU с эмблемой

> ⚠ PNG-изображения продукта и `badge.png` — **сгенерированные плейсхолдеры**
> (исходных фото не было в окружении сборки). Заменяются финальной
> фотографией без изменения путей. Подробности — в [`REPORT.md`](REPORT.md).

## Локальный запуск

Сборка не нужна — это статика. Любой статический сервер:

```bash
npx serve .        # или: python3 -m http.server 8000
```

Открыть `http://localhost:3000` (или `:8000`).

## Деплой

Хостинг — **Vercel**, framework preset = *Other*, output = корень репозитория
(`vercel.json` уже настроен). Пуш в `main` → автоматический прод-деплой.
Пошаговая инструкция — в [`REPORT.md`](REPORT.md).

## Ветки

- `main` — релизная, привязана к прод-деплою Vercel.
- `develop` — рабочая, сюда идут все правки.

(В текущем окружении агента работа ведётся в служебной ветке — см. `REPORT.md`.)
