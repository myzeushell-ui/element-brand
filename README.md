# ЭЛЕМЕНТ — премиальный лендинг (светлая тема, 3 варианта)

Сайт компании **ЭЛЕМЕНТ** — производителя газопоршневых установок (ГПУ) для
майнинга, промышленных предприятий, котельных и аквакультуры. Премиум-сегмент,
**светлая тема** (по предпочтению заказчика), фирменный знак — пламя, акцент —
красный.

Главная страница сделана в **трёх вариантах**: один бренд и один контент, но
три разные «фишки» на заставке.

## Структура

| Файл | Назначение |
|------|------------|
| `index.html`     | Витрина-выбор: три варианта с живыми превью |
| `variant-1.html` | **«Живой двигатель»** — интерактивная 3D-модель ГПУ (three.js) в светлой студии |
| `variant-2.html` | **«Кинетическое пламя»** — живое пламя из частиц (canvas) как апофеоз энергии |
| `variant-3.html` | **«Поток энергии»** — пульсирующая волна мощности и счётчик кВт в реальном времени |
| `assets/element-light.css` | Общая премиальная светлая тема |
| `assets/sections.js`       | Единый контент (nav, секции, форма, футер, переключатель 1·2·3) |
| `assets/flame.svg`         | Знак-пламя |
| `assets/img/genset.svg`    | Векторная иллюстрация ГПУ (плейсхолдер под фотосъёмку) |
| `tools/genengine.js`       | Генератор иллюстрации ГПУ |
| `vercel.json`              | Статика: framework=Other, output=корень, cleanUrls |

На каждом варианте внизу справа — переключатель **1·2·3** для быстрого сравнения.

## Контент

Структура и цифры взяты из присланных макетов и адаптированы под премиум:
герой «Энергия для развития бизнеса», показатели (8000 м², 480 установок/год,
100% собственное производство), отраслевые решения (майнинг, переработка,
котельные, аквакультура), ценности, продукция (ГПУ 210/230 кВт), форма заявки.

## Локальный запуск

Сборка не нужна — статика:

```bash
npx serve .        # или: python3 -m http.server 8000
```

## Деплой

Vercel, framework preset = *Other*, output = корень (`vercel.json` готов).
Пуш в `main` → автодеплой прод. Пошагово — в [`REPORT.md`](REPORT.md).

## Ветки

- `main` — релиз/прод; `develop` — рабочая.
